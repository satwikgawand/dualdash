# DualDash

DualDash is a standalone GPS car HUD for Android. It shows live speed, heading and location, and works in HUD mirror mode (windshield reflection) and drive mode. No OBD-II adapter or car pairing is required — GPS only.

**Status: Milestone 1 — a drive-testable speed HUD.** The app scaffolds, builds, and implements the research-bound GPS pipeline with Drive + HUD modes. It is realtime-only and stores nothing: no trip logging, no local database, no sync (SPEC M1-O5). Not yet drive-tested on a device. The plan, decisions and open questions live in [`docs/SPEC.md`](docs/SPEC.md). Research findings live in [`docs/research/`](docs/research/).

## What v1 does

- Speed readout from GPS, large enough to read while driving.
- HUD mirror mode (mirrored image for windshield reflection) and drive mode.
- Heading / compass direction.

## What v1 does not do

- No OBD-II / car diagnostics.
- No turn-by-turn navigation.
- No speed-limit warnings (see `docs/research/speed-limits.md` for why).
- No trip logging, saved data or sync of any kind — realtime display only.

## Develop, test, build

```bash
npm install
npm run dev        # browser dev server with a mock GPS trace
npm test           # Vitest unit suite (pipeline math + synthetic traces)
npm run build      # tsc typecheck + Vite production build to dist/
npx cap sync       # copy web assets + plugin config into android/
```

The browser build runs on a synthetic GPS trace so the UI is exercisable without hardware. The Capacitor build (`Capacitor.isNativePlatform()`) switches to the real `watchPosition` fused stream. Build the APK on a machine with the Android SDK (`npx cap open android`, then Gradle) — this repo does not run Gradle.
