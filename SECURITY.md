# Security Policy

## Supported versions

Only the latest published version on the [Releases page](https://github.com/satwikgawand/dualdash/releases) receives fixes.

## Reporting a vulnerability

Do not open a public issue.

1. Preferred: use **GitHub Security Advisories** on this repository (Security → Report a vulnerability).
2. Alternative contact: <!-- OWNER TO FILL IN: email or other private contact channel --> `[contact to be added by the owner]`

Include the version, the device, the steps to reproduce, and the impact. You get a reply when the report is read and triaged.

## Scope notes

DualDash runs offline. It has no backend, no accounts, and no analytics. The app reads GPS speed and heading, and it stores nothing. A security report is most useful when it names the Android version, the device, and the exact build (versionCode).
